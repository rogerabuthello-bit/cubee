# Cubee Meta Ad 01 - Instagram Waitlist

## Campaign Goal

Drive early waitlist signups for Cubee at:

https://cubee.rogello.com

This first ad should be treated as a validation campaign, not a scale campaign.

## Recommended Campaign Setup

- Campaign objective: Traffic
- Conversion location: Website
- Performance goal: Landing page views, if available
- Placement: Instagram only
- Placements to use:
  - Instagram Feed
  - Instagram Stories
  - Instagram Reels
- Daily budget: CAD $10-$20 for 5-7 days
- Campaign name: `Cubee - Waitlist - IG - V1`
- Ad set name: `Broad - Canada/US - Moodwear`
- Ad name: `Still Loading Model - 4x5`

## Audience

Start broad. Do not over-target the first test.

- Location: Canada and United States
- Age: 18-34
- Gender: All
- Detailed targeting, optional:
  - streetwear
  - graphic tees
  - lifestyle brand
  - mental wellness
  - cute characters
  - anime / kawaii culture
  - casual fashion

If Meta recommends Advantage detailed targeting, leave it on for the first test.

## Creative

Upload:

`cubee-waitlist-instagram-feed-4x5.png`

Format:

- 4:5 feed creative
- 1080 x 1350
- Best for Instagram Feed
- Can also be cropped for Reels/Stories, but a separate 9:16 creative would be better later.

## What To Watch

After 3-5 days, review:

- Cost per landing page view
- Click-through rate
- Waitlist signups in Google Sheets
- Which placement gets the cleanest traffic

If people click but do not join the waitlist, improve the landing page or add a stronger promise.

If people do not click, test a new creative or stronger first line.

## Next Improvement

Install Meta Pixel before running conversion campaigns. Without Pixel/event tracking, Meta cannot properly optimize for waitlist submissions.
